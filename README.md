# 🪄 Wander & Wonder

## Explore the Four Houses of Hogwarts

Wander & Wonder is a beginner front-end web development project inspired by the Harry Potter universe. It was created as one of my first projects while learning the fundamentals of HTML, CSS, and JavaScript.

The website introduces the four Hogwarts houses—Gryffindor, Slytherin, Ravenclaw, and Hufflepuff—along with their founders, values, symbols, and notable members.

🌐 **Live Demo:** https://jenifervincya.github.io/wander-and-wonder/

---

## ✨ Features

* Information about all four Hogwarts houses
* House crests and descriptions
* Simple navigation menu
* Responsive webpage layout
* Beginner-friendly design and structure

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose of the Project

This project was built to practice:

* Creating webpage layouts using HTML
* Styling pages with CSS
* Basic JavaScript concepts
* Responsive web design
* Organizing a simple front-end project

As one of my first front-end projects, it helped me understand how different web technologies work together to create an interactive website.

---

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/jenifervincya/wander-and-wonder.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
